# Fast Rust file Explorer - fre

Keybindings:
 - Arrows or Ctrl + H,J,K,L : navigate
 - Space bar : go into directory or open file
 - Ctrl + Q: quit
 - Ctrl + Shift + H: return to home
 - Enter: open directory with kitty or file with system default app
 - Ctrl + E: open directory or file's parent directory with nemo
 - PageUp, PageDown: scroll preview
 - Ctrl + T: toggle preview
 - Any key: filter results
 - Backspace, Esc: clear filter
